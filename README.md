# 肿瘤临床试验趋势分析（ClinicalTrials.gov数据分析项目）

## 📌 项目背景
临床试验是药物研发的核心环节。ClinicalTrials.gov作为全球最大的临床试验注册数据库，记录了超过50万项研究的信息。本项目利用ClinicalTrials.gov公开数据，对**非小细胞肺癌（NSCLC）**领域临床试验进行深度分析，旨在揭示该领域的研发趋势、成功率影响因素和关键成功要素。

## 🎯 分析目标
- **趋势分析**：2019-2025年NSCLC临床试验的年度变化趋势与成功率演变
- **阶段分布**：不同试验阶段（Phase 1/2/2/3）的分布特征与成功率差异
- **竞争格局**：不同申办方类型（Big Pharma/Biotech/学术机构）的表现对比
- **疗法热点**：靶向治疗、免疫治疗、联合疗法等策略的成功率分析
- **规模效应**：入组规模与试验成功率的关联性研究

## 📊 数据来源
- **来源**：[ClinicalTrials.gov](https://clinicaltrials.gov/) - 美国国立医学图书馆临床试验数据库
- **检索条件**：
  - 疾病领域：非小细胞肺癌（Non-Small Cell Lung Cancer）
  - 研究类型：干预性研究（Interventional Studies）
  - 时间范围：2019-2025年
  - 数据下载格式：CSV（自定义字段）
- **数据规模**：**2,441条**临床试验记录

## 🛠️ 技术栈
- **语言**：Python 3.9.23
- **数据处理**：Pandas, NumPy
- **可视化**：Matplotlib, Seaborn
- **开发环境**：Python 脚本（Jupyter Notebook 可选）
- **协作方式**：与AI协同完成需求拆解、代码生成与优化

## 📈 分析流程
1. **数据获取**：从ClinicalTrials.gov下载NSCLC相关试验数据
2. **数据清洗**：处理缺失值、统一日期格式、规范分类字段、创建衍生指标
3. **探索性分析**：时间趋势、阶段分布、申办方分析、疗法类型、入组规模
4. **可视化呈现**：生成8张核心分析图表
5. **业务洞察**：提炼5大核心发现，形成战略建议

## 🔍 核心发现

### 发现一：临床试验成功率持续下滑，行业面临"效率危机"
- **2019年成功率高达63.6%，2025年骤降至11.1%**，降幅超过80%

> ⚠️ 方法学说明：2024–2025 年试验大多仍处于 Ongoing（尚未出结果），按年统计的"成功率"分母仅含已裁决试验，存在右删失（right-censoring）；近期数值下滑主要反映试验尚未成熟，而非真实趋势。更稳健的结论请参考下方截面维度（Phase 2/3 设计、入组规模、申办方类型）。
- 59.9%的试验仍处于Ongoing状态，Failed率（14.3%）超过Completed率（10.9%）
- **洞察**：随着PD-1/L1标准疗法确立，新药差异化空间被压缩，试验设计复杂度增加，导致成功率断崖式下跌

### 发现二：Phase 2/3无缝衔接设计成功率最高，传统分阶段设计存在"死亡之谷"
- **Phase 2/3成功率60.0%**（最高）vs **Phase 1/2成功率32.7%**（最低）
- Phase 1成功率43.1%，Phase 2成功率44.8%，Phase 3成功率55.4%
- **洞察**：无缝衔接设计通过减少试验间"空窗期"和患者流失，显著提升成功率，建议优先采用适应性试验设计（Adaptive Trial Design）

### 发现三：Big Pharma并非"常胜将军"，学术机构表现亮眼
- **Big Pharma成功率45.6%** vs **学术机构成功率44.6%**（几乎持平）
- **Biotech成功率最低37.5%**，可能受资金压力和经验不足影响
- 学术机构主导33.6%的试验，在Phase 2阶段占比高达53.7%
- **洞察**：学术机构凭借早期创新靶点探索和灵活设计，竞争力不逊于大型药企，建议Biotech寻求学术合作降低风险

### 发现四：入组规模与成功率呈强正相关，"小而美"策略失效
| 入组规模 | 占比 | 成功率 |
|---------|------|--------|
| <50人 | 41.4% | 42.2% |
| 50-100人 | 19.9% | 59.8% |
| 100-300人 | 23.4% | 62.8% |
| 300-1000人 | 14.4% | 82.6% |
| **>1000人** | **0.9%** | **100.0%** |

- **洞察**：41.4%的试验入组<50人，但成功率仅42.2%；大规模试验（>1000人）成功率达100%。建议设定样本量底线≥100人，避免资源过度分散

### 发现五：联合疗法成为主流，但靶向治疗成功率最高
- **Other/Combination疗法占78.4%**（1,913项），但成功率仅43.4%
- **靶向治疗成功率71.4%**（最高），但仅占1.5%的试验
- 免疫治疗成功率50.0%，细胞/基因疗法成功率最低20.0%
- **洞察**："组合"不等于"成功"，单纯靶向治疗成功率远超联合疗法。建议联合方案基于明确生物学机制，避免盲目跟风"免疫+化疗"标准组合

## 🚀 如何复现
> 数据已随仓库提供（`clinical_trials_project/data/ctg-studies.csv`），无需自行下载即可复现。

1. 克隆仓库：`git clone https://github.com/wtang5407-source/nsclc-clinical-trials-analysis.git`
2. 进入项目目录：`cd nsclc-clinical-trials-analysis/clinical_trials_project`
3. 安装依赖：`pip install -r requirements.txt`
4. 依次运行（按顺序；02 的产物供 03 使用）：
   ```bash
   python scripts/01_data_exploration.py
   python scripts/02_data_cleaning.py
   python scripts/03_eda_analysis.py
   ```
图表输出在 `outputs/eda_figures/`，报告在 `outputs/reports/`。

## 💡 战略建议

| 优先级 | 建议内容 | 适用对象 | 预期效果 |
|:---|:---|:---|:---|
| ⭐⭐⭐⭐⭐ | 采用Phase 2/3无缝衔接设计 | 所有申办方 | 成功率从32.7%提升至60.0% |
| ⭐⭐⭐⭐⭐ | 确保关键试验入组规模≥100人 | Biotech、学术机构 | 避免"小样本陷阱"，成功率提升至60%+ |
| ⭐⭐⭐⭐ | 加强与学术机构合作 | Biotech | 借助学术机构经验，缩小与Big Pharma差距 |
| ⭐⭐⭐⭐ | 联合疗法设计需基于明确生物学机制 | Big Pharma | 避免盲目组合，提升联合疗法成功率 |
| ⭐⭐⭐ | 建立动态成功率监控机制 | 所有申办方 | 及时止损低效项目，优化资源配置 |

## ⚠️ 数据局限性

1. **时间偏差**：2024-2025年试验多为Ongoing状态，成功率数据可能偏低
2. **结果定义**："Completed"不等于"临床成功"，未考虑是否达到主要终点
3. **疗法分类**："Other/Combination"类别过于宽泛，需进一步细分
4. **地域分布**：未区分中美欧等不同监管环境下的成功率差异
5. **样本偏差**：NSCLC单癌种分析，结论外推至其他瘤种需谨慎
